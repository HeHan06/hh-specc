# 业务层知识：核心数据模型（data-model）

> 层级：业务层 ｜ 状态：🤖 机器起草（bootstrap 临时模式）——2026-08-22 由 specc 起草，**用户已批准生效**

## 1. 核心实体清单

| 实体 | 说明 | 关键字段 | 关联实体 |
|---|---|---|---|
| 语录 Quote | 每日展示的核心内容单元 | id、content(语录正文)、source(书名/作者)、display_date(展示日期)、background_image(背景图URL)、status(上架状态)、created_at | — |

## 2. 状态机

```
语录状态（简单，仅两态）：
  草稿(draft) → 已上架(published)

说明：
  - 草稿：已录入但未到展示日期，或运营者暂存，不对读者可见。
  - 已上架：到达 display_date 当天自动对读者可见。
  - 无删除操作，运营者只能将已上架改回草稿（软隐藏），保留记录。
```

## 3. 关键业务规则（数据层面）

- 每个 display_date 在同一天内最多只有一条状态为「已上架」的语录（唯一性约束）
- 背景图以 URL 形式存储（测试阶段使用本地静态图或预置图片链接），不存二进制
- 语录正文与出处均不为空；出处格式统一为「《书名》—— 作者」
- 无历史浏览需求，因此不需要阅读记录表
