# UI 预设：landing-page（营销落地页范式）

> 一句话愿景：**让"对外宣传/产品官网"长得像"可信赖的现代产品"——首屏抓眼、故事线清晰、行动点明确，访客愿意往下滑并点击注册。**
> 适用产品：SaaS 官网、产品介绍页、活动推广页、App 拉新落地页、品牌首页。
> 何时**不**用：内部管理系统/数据看板（用 `dashboard-admin`）；纯移动端流式（用 `mobile-content-feed`）。

## 设计令牌（视觉唯一权威源）

> 取值只准来自这里，禁止在页面硬编码。与 dashboard-admin 不同：落地页**底色偏亮、强调色更醒目、留白更大**，用情绪而非信息密度打动人。

### 色板
| 令牌 | 值 | 用途 |
|---|---|---|
| `--color-bg` | `#ffffff` | 页面底色（纯白，干净） |
| `--color-primary` | `#4f46e5`（靛蓝） | 主 CTA、链接、重点强调 |
| `--color-accent` | `#f59e0b`（琥珀） | 次级营销色（徽标/亮点） |
| `--color-text` | `#111827` | 大标题 |
| `--color-text-secondary` | `#6b7280` | 正文/描述 |
| `--color-surface-muted` | `#f9fafb` | 区块交替背景（浅灰） |
| `--color-border` | `#e5e7eb` | 分隔/卡片描边 |

### 字号（更大、更有层次）
`16 → 20 → 24 → 36 → 56`（正文 / 副标 / 小标题 / 区块标题 / 首屏大标题）。首屏 H1 用 48~56，营造冲击。

### 间距（宽松）
`8, 16, 24, 48, 96`。区块间距 96（大留白），首屏内边距 96~128。

### 圆角 & 阴影
- 圆角：`16`（卡片）/ `8`（按钮）——更柔和现代
- 阴影：`0 10px 30px rgba(0,0,0,0.08)`（卡片浮起感，一级）

## 布局骨架（标准五区，自上而下）

```
┌──────────────────────────────────────────────┐
│ 导航 Nav（透明→滚后实底，右侧 CTA 按钮）        │
├──────────────────────────────────────────────┤
│ Hero 首屏（全宽，居中，大字 + 副文案 + 双按钮 ） │
│   H1 + 一句话副文案 + [立即开始][了解详情]       │
├──────────────────────────────────────────────┤
│ 信任背书 SocialProof（Logo 墙 / 数据条）        │
├──────────────────────────────────────────────┤
│ 特性区 Features（2~3 列卡片，每卡图标+标题+描述） │
├──────────────────────────────────────────────┤
│ 产品截图 / 场景展示（大图，代替自夸，展示实况）    │
├──────────────────────────────────────────────┤
│ CTA 区（大标题 + 按钮，制造行动冲动）            │
├──────────────────────────────────────────────┤
│ 页脚 Footer（链接分组 + 版权 + 社交）            │
└──────────────────────────────────────────────┘
```

## 组件清单（用 Ant Design 元素 + 少量自定义样式）

| 区块 | 推荐实现 |
|---|---|
| 导航 | 自绘 header（`Affix` 实现吸顶），右侧 `Button` 主 CTA |
| Hero 首屏 | `Typography.Title/Paragraph` + `Space` + 大号 `Button`(主+次) |
| 信任背书 | 纯 logo 图片流 / `Row+Col` 数据条 |
| 特性区 | `Row`/`Col` 栅格 + `Card`（或自绘卡片），图标 + 标题 + 描述 |
| 产品截图 | 大图 `Image`，配 `Box` 容器（圆角+阴影） |
| CTA 区 | 居中 `Title` + 大 `Button` |
| 页脚 | `Layout.Footer` + 链接分组 |

> 说明：落地页视觉自由度高于后台，常用**少量自定义 CSS**做留白/间距/大标题，但颜色、圆角、阴影仍走令牌，禁止散落的魔法色值。

## 组件纪律（反模式）

- **禁止**堆信息密度：落地页是"讲故事"不是"塞数据"，一屏只讲一个重点。
- **禁止**用表格/复杂表单做主视觉——落地页的 CTA 越简单越好（尽量只留一个主按钮）。
- **禁止**手写 `<button>` 并配散落颜色——主按钮用 Ant `Button type=primary` + 令牌色，其余用 `type=default`。
- 每个区块要有明确"下一跳"（向下滑或点击），避免死胡同。
- 移动端必须有响应式换算（栅格断点塌缩），遵循 F-04 中"页面薄、状态清晰"。
- 页面结构按 `frontend-architecture.md`：Page → service → api → shared；落地页多为静态展示，允许不建 service（F-03-4）。

## 首屏写法示例（抛砖引玉）

```jsx
// pages/Home.jsx
import { Button, Typography, Row, Col, Card, Image } from 'antd';
// @capability Req-1 产品官网首页
function Home() {
  return (
    <div>
      <HeaderCTA />                 {/* 吸顶导航 + 右侧 CTA */}
      <section className="hero">    {/* 首屏：居中大字 + 双按钮 */}
        <Title>一句话说清你的产品价值</Title>
        <Paragraph>给用户一个值得看下去的副文案。</Paragraph>
        <Space><Button type="primary" size="large">立即开始</Button>
               <Button size="large">了解详情</Button></Space>
      </section>
      <SocialProof />               {/* Logo 墙 / 数据 */}
      <Features />                  {/* 2~3 列特性卡片 */}
      <ProductShot />               {/* 大图展示 */}
      <CTA />                       {/* 行动号召 */}
      <Footer />
    </div>
  );
}
```
