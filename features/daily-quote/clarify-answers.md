# 澄清答案（人工提供）

> 说明：以下 8 项为需求方对 spec.md 第 5 节「待澄清清单」的确认答案。
> clarify 阶段请据此回填 spec.md，消除全部 `[NEEDS CLARIFICATION]` 标记，
> 并在 clarify.md 中记录问答、回答人、时间与对规格的影响。

| # | 对应待澄清项 | 确认答案 |
|---|---|---|
| 5.1 | 「今天」时区与切换点 | 以 Asia/Shanghai 时区为准，每日 0 点整切换 |
| 5.2 | Web 展示页承载形态 | 独立展示页（纯展示，无管理界面）；访问入口为后端静态页面路由 |
| 5.3 | 语录正文字数上限 | 单条 ≤ 60 字；超出时截断显示并保留出处完整 |
| 5.4 | 背景图规格 | 单图 ≤ 500KB，竖屏优先；Web 端用同一张图居中裁切适配宽屏 |
| 5.5 | 鉴权白名单 / 限流 | 每日语录查询接口列入鉴权白名单；MVP 不做限流防刷（记入「不做什么」） |
| 5.6 | 同语录跨日期复用 | 允许复用（同一条语录可排多个展示日期）；唯一性约束按「日期」而非「语录」 |
| 5.7 | 是否展示日期信息 | 展示当天日期（页面上显示日期，增强「每日」感） |
| 5.8 | 接口响应时间目标 | P95 ≤ 500ms（本地单表查询，易达成） |
