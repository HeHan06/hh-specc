# 业务层知识：业务背景与领域模型（business）

> 层级：业务层（每个业务项目初始化一份）
> 状态：🤖 机器起草（bootstrap 临时模式）——2026-08-22 由 specc 根据用户自然语言需求与澄清结论起草，**用户已批准生效**

## 1. 业务背景

「每日一句」是一个轻量内容展示产品：每天为读者展示一段选自容易引发共鸣的文学作品的引人深思的句子（如《自渡》中的「人生自苦，他人难悟，唯有自爱，方能自渡」），配以一张清新的背景图，前端以精致的排版呈现。读者通过微信小程序与 Web 页面两个端阅读；内容由运营方预先准备好语料与配图，按日期自动上架，读者端无管理功能。

## 2. 领域术语表

| 术语 | 定义 | 对应代码命名建议（英文） |
|---|---|---|
| 语录 | 从文学作品中精选的一段文字，附书名/作者出处 | quote |
| 展示日期 | 语录对读者可见的日期，每日仅展示一条 | display_date |
| 背景图 | 与语录搭配的清新风格配图 | background_image |
| 兜底内容 | 今日无上架语录时展示的默认语录+默认图，避免白屏 | fallback |

## 3. 角色模型

| 角色 | 使用端 | 核心权限 |
|---|---|---|
| 读者 | 小程序 + Web 展示页 | 查看当日语录（只读，无账号、无历史浏览） |
| 运营者 | （MVP 阶段不经系统操作） | 语料与配图以测试数据预置入库，无后台界面 |

## 4. 业务红线

- 任何一天对读者展示的语录有且只有一条（当日无内容则展示兜底内容，绝不白屏）
- 语录内容一经发布不得静默变更（展示历史可追溯）
- 语料版权：测试数据应选用公版作品或短摘录，注明来源（书名+作者）
