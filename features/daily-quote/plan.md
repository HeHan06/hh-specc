# 技术方案：daily-quote

## 1. 方案概述

「每日一句」为双端只读展示系统：微信小程序与 Web 展示页各自调用同一个后端公开接口获取当日语录；后端按 `Asia/Shanghai` 时区计算展示日期，查询当日已上架语录，无内容时返回预置兜底内容。MVP 不提供运营后台与 CRUD 接口，语料、配图与兜底内容以 PostgreSQL 迁移/种子脚本预置入库，通过查询时按日期过滤实现“自动上架”，无需定时任务。Web 展示页是独立纯展示页，由后端以静态页面路由提供，不复用管理后台页面；共享层负责 API 客户端、文案截断、日期格式化与兜底常量，避免双端重复实现。

关键取舍：仅保留一个公开查询接口，减少鉴权与后台范围；唯一性用 PostgreSQL 部分唯一索引兜底；时间口径在 Java 服务端显式指定，不依赖数据库会话时区。

## 2. 前端设计

### 2.1 Web 后台（web-admin/）

| 页面/路由 | 功能 | 对应需求 |
|---|---|---|
| `/` | 当日语录独立展示页：背景图、正文、出处、当天日期四要素；接口失败时展示本地兜底文案 | Req-1、Req-4、Req-5、Req-6 |

说明：本期 `web-admin/` 仅承载展示页，不实现登录、菜单、RBAC 或管理表格。工程仍按 React 18 + JavaScript + Vite + Ant Design 脚手架创建，但展示页使用 React + 普通 CSS/CSS Modules 排版，不引入 Ant Design 之外的 UI 库。构建产物由后端以静态路由托管：`/` 返回 `index.html`，非 `/api` 的未知前端路由回退到 `index.html`。

### 2.2 小程序（miniprogram/）

| 页面 | 功能 | 对应需求 |
|---|---|---|
| `pages/quote/index` | 当日语录展示页：背景图、正文、出处、当天日期四要素；接口失败时展示本地兜底文案 | Req-1、Req-4、Req-5、Req-6 |

页面在 `app.config.js` 中声明为首页；不配置 `tabBar`、不采集用户信息、不申请隐私权限。微信特有请求能力统一封装在 `src/platform/request.js`，页面不裸调 `wx.*`。

### 2.3 双端共享（shared/）

| 共享项 | 类型（常量/工具/校验规则/API客户端） | 说明 |
|---|---|---|
| `shared/types/quote.js` | 类型定义 | JSDoc 定义 `QuoteView`：`content`、`source`、`backgroundImage`、`displayDate` |
| `shared/constants/quote.js` | 常量 | `MAX_CONTENT_LENGTH=60`、接口路径 `/api/quotes/today`、接口失败时的本地兜底文案 |
| `shared/constants/error-code-text.js` | 常量 | 通用错误码与业务错误码对应的前端默认文案映射 |
| `shared/utils/quote.js` | 工具 | `truncateQuoteText(content, maxLength)`、`formatShanghaiDate(date)` |
| `shared/api/client.js` | API客户端 | 平台无关的 API 客户端基座；通过注入的 `request` 适配器执行请求，统一解包响应体 |
| `shared/api/quote.js` | API客户端 | `getTodayQuote()`：调用公开接口并做最小响应归一化 |

规则：`shared/` 不放 DOM、`wx.*`、React 组件或路由逻辑；两端分别注入 HTTP 适配器（Web 用 `fetch`，小程序用 `wx.request` 封装）。

## 3. 后端设计（backend/）

- 涉及模块：`com.dailyquote.quote`
- 关键类/分层职责：
  - `QuoteController`：`GET /api/quotes/today`，公开接口（鉴权白名单），无入参，返回统一响应体 `ApiResponse<QuoteView>`。
  - `QuoteService`：使用 `ZoneId.of("Asia/Shanghai")` 计算 `LocalDate`；查询当日已上架语录；无结果时读取 `system_config` 兜底配置并组装 `QuoteView`。
  - `QuoteMapper`：MyBatis Mapper，仅使用 `#{}` 参数化查询 `display_date = #{displayDate} AND status = 'published'`，`LIMIT 1`。
  - `SystemConfigMapper`：按 `config_key` 读取兜底内容配置。
  - `QuoteView`：响应 DTO，字段与契约一致。
- 事务与并发要点：
  - 读取路径标记为只读；本期无写接口，事务边界简单。
  - 自动上架无需调度器：请求时刻按上海日期过滤即可。
  - 并发写入仅发生在预置迁移阶段，由 PostgreSQL 部分唯一索引保证“每个日期最多一条已上架语录”。
  - 所有日期计算均在服务端完成，客户端不传日期，避免时区篡改。

- 需求落点：
  - Req-1：双端页面 + `GET /api/quotes/today` 返回四要素。
  - Req-2：`QuoteService` 按上海日期查询，无定时任务即自动上架。
  - Req-3：`quote` 表部分唯一索引 + 预置脚本幂等写入。
  - Req-4：`system_config` 兜底配置 + `QuoteService` 无结果时回退。
  - Req-5：两端页面各自的本地兜底渲染分支。
  - Req-6：`GET /api/quotes/today` 鉴权白名单，双端无账号入口。
  - Req-7：版本化迁移 + `updated_at` 触发器，无静默修改路径。
  - Req-8：`quote` 表 `CHECK` 约束校验正文、出处格式与图片非空。

## 4. 数据模型（PostgreSQL）

```sql
-- backend/src/main/resources/db/migration/V1__init_quote.sql

CREATE TABLE IF NOT EXISTS quote (
    id                BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    content           VARCHAR(60)  NOT NULL,
    source            VARCHAR(120) NOT NULL,
    display_date      DATE         NOT NULL,
    background_image  VARCHAR(500) NOT NULL,
    status            VARCHAR(16)  NOT NULL DEFAULT 'draft',
    created_at        TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at        TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT ck_quote_content_not_blank CHECK (length(btrim(content)) > 0),
    CONSTRAINT ck_quote_source_format CHECK (source ~ '^《[^》]+》—— .+$'),
    CONSTRAINT ck_quote_status CHECK (status IN ('draft', 'published'))
);

-- 每个展示日期最多一条已上架语录；草稿可存在多条（符合“按日期唯一”边界）
CREATE UNIQUE INDEX uk_quote_published_display_date
    ON quote (display_date)
    WHERE status = 'published';

CREATE OR REPLACE FUNCTION set_updated_at()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = CURRENT_TIMESTAMP;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_quote_updated_at
    BEFORE UPDATE ON quote
    FOR EACH ROW EXECUTE FUNCTION set_updated_at();

CREATE TABLE IF NOT EXISTS system_config (
    config_key    VARCHAR(64)  PRIMARY KEY,
    config_value  TEXT         NOT NULL,
    description   VARCHAR(255),
    updated_at    TIMESTAMPTZ  NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TRIGGER trg_system_config_updated_at
    BEFORE UPDATE ON system_config
    FOR EACH ROW EXECUTE FUNCTION set_updated_at();
```

兜底内容种子（随同一迁移目录的 `V2__seed_fallback_quote.sql` 执行）：

```sql
INSERT INTO system_config (config_key, config_value, description) VALUES
    ('fallback.quote.content', '人生自苦，他人难悟，唯有自爱，方能自渡', '当日无上架语录时展示的默认正文'),
    ('fallback.quote.source', '《自渡》—— 佚名', '默认出处'),
    ('fallback.quote.backgroundImage', '/assets/images/fallback-bg.png', '默认背景图')
ON CONFLICT (config_key) DO UPDATE SET config_value = EXCLUDED.config_value;
```

- 迁移策略：版本化 SQL 位于 `backend/src/main/resources/db/migration/`，按 `V1__init_quote.sql`、`V2__seed_fallback_quote.sql` 顺序执行；开发/测试环境通过 `psql "$DATABASE_URL" -f <file>` 应用。MVP 不引入 Flyway/Liquibase，避免新增清单外依赖；后续如需自动迁移，须回到 plan 阶段审批。
- 数据约束落点：正文非空、正文 ≤ 60 字、出处格式、背景图非空由 DDL `CHECK` 承担；每日唯一性由部分唯一索引承担；`updated_at` 由触发器维护，满足内容可追溯要求。

## 5. 接口契约

- 契约文件：`contracts/quote.yaml`（格式依据 `platform/api-conventions.md` 第 5 节）
- 本需求错误码段：每日一句（quote） → `2000-2099`

说明：本期仅 1 个无分页公开接口；契约文件仍显式声明分页强制格式，作为后续列表接口的约束，当前不落分页端点。

## 6. 关键技术决策与理由

| 决策 | 备选 | 选择理由 |
|---|---|---|
| 仅暴露 `GET /api/quotes/today`，不做后台 CRUD API | 增加语料管理接口 | spec 明确本期无后台界面；预置走版本化 SQL，范围最小 |
| 上海日期由 Java 服务端 `ZoneId.of("Asia/Shanghai")` 计算 | 依赖数据库 `CURRENT_DATE` | 明确满足 5.1 时区口径，避免 DB 会话时区漂移 |
| 唯一性用 PostgreSQL 部分唯一索引 | 普通唯一索引 | 同一日期允许多条草稿，只限制“已上架”一条，符合 5.6 |
| 兜底内容存入 `system_config` | 写入 Java 常量或环境变量 | 兜底内容属运营预置数据，入库可追溯、免发版修改 |
| `shared/api/client.js` 用注入式 `request` 适配器 | 双端各写请求逻辑 | 遵守宪法 4.4 与双端边界规约，两端复用同一接口定义 |
| 前端测试栈采用 Vitest；Web 可渲染测试用 React Testing Library；小程序用 Taro 官方测试工具 | 不测页面/仅构建校验 | 满足宪法 3.3“页面组件至少保证可渲染” |
| 依赖版本锁定：React 18.3.x、Vite 5.x、Ant Design 5.x、Taro 3.6.x、Spring Boot 3.2.x、MyBatis Spring Boot Starter 3.0.x、PostgreSQL JDBC 42.7.x | 采用最新大版本 | 与宪法第一条匹配，且锁大版本便于审查；新增测试依赖 Vitest、React Testing Library、jsdom、Taro 测试工具均为 devDependency，理由为满足第三条测试门禁 |

## 7. 风险与验证

- 风险：
  - 出处格式的 PostgreSQL 正则较严格，若真实语料出现“书名/作者”变体，需回到 plan 调整契约与 DDL。
  - 小程序图片域名需配置微信后台合法域名，且背景图须为 HTTPS/CDN 资源；否则图片无法加载，触发本地兜底。
  - Web 静态路由回退不能吞掉 `/api/*`，后端需先匹配 API，再回退 `index.html`。
  - 接口失败时，两端本地兜底文案须独立渲染路径可测，避免“本地兜底也白屏”。
- 验证命令（供 tasks 阶段引用）：
  - 后端：`cd backend && ./mvnw test`
  - 数据库迁移：`psql "$DATABASE_URL" -f backend/src/main/resources/db/migration/V1__init_quote.sql && psql "$DATABASE_URL" -f backend/src/main/resources/db/migration/V2__seed_fallback_quote.sql`
  - 共享层：`npm run test:shared`
  - Web 展示页：`cd web-admin && npm run test && npm run build`
  - 小程序：`cd miniprogram && npm run test && npm run build:weapp`
