# 数据模型：ai-guide

> 本文件描述业务层核心实体、状态机与数据层面业务规则。实体属性为业务概念，具体字段命名、存储结构与接口契约在 plan 阶段再细化。

## 1. 核心实体清单

| 实体 | 业务含义 | 关键业务属性（概念层） |
|---|---|---|
| 主题（Topic） | 内容一级分类 | 唯一编码、名称、简介、显示顺序、启用状态 |
| 专题（Category） | 主题下的二级分类 | 唯一编码、所属主题、名称、简介、显示顺序、状态 |
| 内容（Content） | 最小内容单元 | 唯一编码、所属专题、类型、标题、摘要、正文、标签、来源、状态、点赞数、浏览数、发布时间、更新时间 |
| 点赞（Like） | 访客对内容的匿名支持 | 关联内容、访客标识（匿名设备号）、创建时间；同一访客同一内容至多一条 |
| 打赏订单（TipOrder） | 访客对内容的打赏留资记录 | 订单号、关联内容（可空）、金额、打赏人联系信息（可选）、留言、状态、创建时间、收款时间 |
| 咨询订单（ConsultationOrder） | 访客付费咨询订单 | 订单号、联系人、联系方式、咨询主题、咨询诉求、计价方式、金额、期望时间、状态、管理员备注、创建时间 |
| 管理员（AdminUser） | 管理后台唯一账号 | 账号、密码凭证、固定单一管理员角色 |

### 1.1 内容类型

内容类型固定为四类：文章、面试复盘、题目、简历优化内容。

### 1.2 内容来源

内容来源固定为两类：原创、迁移。

## 2. 状态机

### 2.1 内容（Content）

```
草稿 ──发布──▶ 已发布 ──更新──▶ 已发布
  ▲              │
  │              ├──下架──▶ 已下架 ──恢复发布──▶ 已发布
  │              │                        └──归档──▶ 已归档
  │              └──归档──▶ 已归档
  └──归档──────────────────▶ 已归档
```

| 当前状态 | 允许动作 | 目标状态 |
|---|---|---|
| 草稿 | 编辑、发布、归档 | 草稿 / 已发布 / 已归档 |
| 已发布 | 更新、下架、归档 | 已发布 / 已下架 / 已归档 |
| 已下架 | 恢复发布、归档 | 已发布 / 已归档 |
| 已归档 | 仅保留，不再展示 | 终态 |

- 内容不自动删除。
- 「下架」为独立状态：下架后内容对访客不可见，但不退回草稿、不丢失发布历史，可恢复发布或归档。

### 2.2 打赏订单（TipOrder）

```
已提交 ──管理员确认收款──▶ 已收款
   │
   └──管理员关闭──▶ 已关闭
```

| 当前状态 | 允许动作 | 目标状态 |
|---|---|---|
| 已提交 | 管理员确认收款 / 关闭 | 已收款 / 已关闭 |
| 已收款 | 终态 | 终态 |
| 已关闭 | 终态 | 终态 |

### 2.3 咨询订单（ConsultationOrder）

```
已提交 ──管理员确认排期──▶ 已确认 ──完成──▶ 已完成
   │                          │
   └──管理员取消──▶ 已取消 ◀──┘
```

| 当前状态 | 允许动作 | 目标状态 |
|---|---|---|
| 已提交 | 管理员确认排期 / 取消 | 已确认 / 已取消 |
| 已确认 | 完成 / 取消 | 已完成 / 已取消 |
| 已完成 | 终态 | 终态 |
| 已取消 | 终态 | 终态 |

- 管理员确认排期时占用免费名额（前 10 个确认订单免费）；未确认订单不产生咨询权益。

## 3. 数据层面业务规则

- 内容可见性：仅「已发布」状态的内容出现在目录、搜索与详情中；草稿、已下架、已归档不可见。
- 点赞唯一性：同一访客同一内容只计一次；后端幂等，重复请求不产生重复计数；重复点击「仅忽略」。
- 浏览数：每次有效阅读累计一次内容浏览数，不采集用户级浏览行为。
- 打赏金额：固定枚举 0.1 / 1 / 5 / 10 / 50 / 100 元；打赏可关联内容，也可不关联具体内容。
- 咨询计价：500 元/半小时；全平台前 10 个「经管理员确认排期」的咨询订单免费（按确认时间先后占用名额）。
- 咨询必填：联系人、联系方式（手机/微信）、咨询主题、期望时间必填；联系方式必须通过格式校验。
- 订单一致性：打赏与咨询均走「加管理员微信」线下收款；管理员确认收款/排期后才流转到收款/确认状态。
- 收款方式：不接入在线支付；访客留资后加管理员微信完成付款，留言按隐私保密处理。
- 并发冲突：内容编辑采用乐观并发控制，更新时校验更新时间/版本，冲突时提示重新加载，不静默覆盖。
- 操作日志：内容删除、订单收款确认、状态变更等敏感操作记录操作者、时间、对象、动作。
- 删除纪律：内容可下架/归档，不自动物理删除；订单与内容编号作为业务追溯依据保留。
