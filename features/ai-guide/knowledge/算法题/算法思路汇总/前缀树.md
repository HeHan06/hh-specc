### 第一部分：什么是前缀树？（直觉类比）

想象你在玩**“单词接龙”**或使用**输入法自动补全**。

- **普通存法（HashSet）**：存了 `"app"` 和 `"apple"`。当你输入 `"app"` 时，系统完全不知道后面还有 `"apple"`，只能全量遍历。
- **前缀树存法（Trie）**：像一个**高压缩比的家族谱**。
  - 根节点不存字符。
  - 每个节点存储**一个字母**。
  - 从根走到某个节点，路径上的字母连起来就是一个**前缀**。
  - **核心魔法**：`"app"` 和 `"apple"` 共享了 `'a' -> 'p' -> 'p'` 这条路，**只存一次**，极致节省查找前缀的时间。

### 第三部分：终极防坑公式模板（Java 版）

这份模板是为了**杜绝你之前遇到的“覆盖”和“指针不动”问题**而设计的。它包含三个层次：

1. **基础版（解决 208）**：存 `isEnd`。
2. **增强版（解决 677/720）**：增加 `passCount`（经过次数）和 `wordCount`（结尾次数），支持重复插入和前缀计数。

> **使用准则**：刷题时，直接复制下面这个 `Trie` 内部类，只需关注 `search` 的逻辑改写即可。

```java
/**
 * 前缀树公式模板（防坑专用）
 * 特点：强制判空、强制移动指针、内置计数
 */
class Trie {

    // 1. 内部节点定义
    private static class TrieNode {
        // 存储子节点（26个小写字母，若含数字/大小写可换 Map）
        private TrieNode[] children;
        // 标记是否为完整单词（基础功能）
        private boolean isEnd;
        // 【扩展功能】经过该节点的单词数量（用于统计前缀出现次数）
        private int passCount;
        // 【扩展功能】以该节点结尾的单词数量（用于处理重复插入）
        private int wordCount;

        public TrieNode() {
            this.children = new TrieNode[26];
            this.isEnd = false;
            this.passCount = 0;
            this.wordCount = 0;
        }
    }

    private final TrieNode root;

    public Trie() {
        root = new TrieNode();
    }

    // ========== 核心公式：插入（记住三连击：判空→新建→移动） ==========
    public void insert(String word) {
        TrieNode node = root;
        for (char ch : word.toCharArray()) {
            int idx = ch - 'a';
            // 【防覆盖关键】先判空，不存在才 new
            if (node.children[idx] == null) {
                node.children[idx] = new TrieNode();
            }
            // 【防指针不动关键】无论新建还是复用，都必须移动到子节点
            node = node.children[idx];
            // 统计：经过该节点的次数+1（可用于查前缀频率）
            node.passCount++;
        }
        // 标记单词结尾，并统计单词个数
        node.isEnd = true;
        node.wordCount++;
    }

    // ========== 查询辅助公式（万能前缀查找，避免重复代码） ==========
    // 作用：返回前缀对应的最后一个节点。若路径中断，返回 null。
    private TrieNode searchPrefix(String prefix) {
        TrieNode node = root;
        for (char ch : prefix.toCharArray()) {
            int idx = ch - 'a';
            if (node.children[idx] == null) {
                return null;
            }
            // 【防指针不动关键】循环末尾必须移动指针
            node = node.children[idx];
        }
        return node;
    }

    // ========== 标准搜索（必须 isEnd == true） ==========
    public boolean search(String word) {
        TrieNode node = searchPrefix(word);
        return node != null && node.isEnd;
    }

    // ========== 标准前缀匹配（只需路径存在） ==========
    public boolean startsWith(String prefix) {
        return searchPrefix(prefix) != null;
    }

    // ========== 【扩展】查询某个单词被插入了多少次（处理重复 insert） ==========
    public int countWord(String word) {
        TrieNode node = searchPrefix(word);
        return node == null ? 0 : node.wordCount;
    }

    // ========== 【扩展】查询以某个前缀开头的单词总数 ==========
    public int countPrefix(String prefix) {
        TrieNode node = searchPrefix(prefix);
        return node == null ? 0 : node.passCount;
    }

    // ========== 【扩展】删除单词（逻辑删除/物理删除） ==========
    public boolean delete(String word) {
        // 1. 先判断是否存在
        if (!search(word)) return false;
        // 2. 递减路径上的 passCount，并清除 isEnd
        TrieNode node = root;
        for (char ch : word.toCharArray()) {
            int idx = ch - 'a';
            node = node.children[idx];
            node.passCount--;
        }
        node.wordCount--;
        if (node.wordCount == 0) {
            node.isEnd = false;
        }
        // 进阶优化：若 passCount == 0，可将 children[idx] 置为 null 释放内存（此处略）
        return true;
    }
}
```

### 第四部分：模板怎么套用到不同题目？

| 题目要求 | 模板使用策略 |
| :--- | :--- |
| **LeetCode 208（基础）** | 直接用 `search` 和 `startsWith`，忽略 `passCount` 和 `wordCount`。 |
| **LeetCode 211（含 `.` 通配符）** | **禁用** `searchPrefix`，改为自己写 `DFS` 递归。但**复用** `TrieNode` 结构和 `insert` 方法。<br>伪代码：`dfs(node, word, index)`，若 `word[index] == '.'` 则遍历 `node.children` 所有非空节点。 |
| **LeetCode 677（键值映射）** | 插入时在结尾节点存 `value`（替换 `wordCount`）。查询前缀时，用 `searchPrefix` 拿到节点，然后遍历该节点的所有子树，累加 `value`。 |
| **LeetCode 720（最长单词）** | `insert` 照旧。查询时，对每个单词拆解前缀，利用 `searchPrefix` 判断每个前缀是否 `isEnd`，以此决定是否合法。 |
| **LeetCode 421（最大异或数）** | **转变思维**：将 `char` 换成 `int bit`（0 或 1），`children[2]`。模板的 `insert` 和 `search` 逻辑**完全不变**，只是遍历 31 到 0 位。 |

### 第五部分：背下这段“心法口诀”

> **插入牢记三步骤：判空新建往下走。**
> **查询牢记两步骤：判空移动往下走。**
> **凡是取了子节点，指针必定要更新。**
> **若要支持重复词，单词计数加上去。**
