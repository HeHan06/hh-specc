图论 DFS 万能模板 = 明确节点（入参） + 遍历邻居（for循环） + 记录状态（visited）。

图在算法题里只有两种长相，你的模板必须能同时覆盖：

#### 模板 A：邻接表 / 邻接矩阵（显式图）

适用于：`List<List<Integer>>`、`int[][] graph`、节点编号从 `0` 到 `n-1`。

java

```
// 伪代码骨架
void dfs(int node, 图数据, boolean[] visited) {
    // ① 终止条件（通常由 visited 在递归前拦截，这里可不写）
    if (visited[node]) return; 
    
    // ② 标记当前节点
    visited[node] = true;
    
    // ③ 处理当前节点的逻辑（比如累加、比较）
    // ... 

    // ④ 遍历邻居
    for (int next : 图.get(node)) {
        if (!visited[next]) {
            dfs(next, 图, visited);
        }
    }
}
```



#### 模板 B：网格 / 矩阵（隐式图）

适用于：二维数组 `grid`，上下左右移动，比如岛屿数量、迷宫。
（这是你将来一定会遇到的，一并给你）

java

```
void dfs(int r, int c, char[][] grid, boolean[][] visited) {
    int rows = grid.length, cols = grid[0].length;
    
    // ① 终止条件（越界 / 已访问 / 不合法）
    if (r < 0 || r >= rows || c < 0 || c >= cols || visited[r][c] || grid[r][c] == '0') {
        return;
    }

    // ② 标记当前格子
    visited[r][c] = true;

    // ③ 处理当前格子逻辑（如统计面积）

    // ④ 遍历四个方向
    int[] dr = {-1, 1, 0, 0};
    int[] dc = {0, 0, -1, 1};
    for (int d = 0; d < 4; d++) {
        dfs(r + dr[d], c + dc[d], grid, visited);
    }
}
```



- **普通遍历（只走一次）**：**进入函数就标记**（如你现在的写法）。
  *理由*：防止走回头路，避免栈溢出。
- **回溯（路径搜索）**：**在递归前标记，递归后撤销标记**（比如全排列、N 皇后）。
  *理由*：这条路走不通要换路，之前占的位置得让出来。
