### 一、单调栈的核心作用（客观定义）

单调栈本质是维护一个**栈内元素按特定顺序（递增或递减）排列**的栈结构。其**唯一核心能力**是：

> **在线性时间复杂度内，为数组中每个元素找到其左侧或右侧第一个满足“大于”或“小于”关系的元素。**

这种能力适用于所有需要**消除逆序对**或**寻找边界**的场景。

---

### 二、适用场景的客观分类

基于单调性的方向（递增/递减）和查询方向（左侧/右侧），可精确划分为四类基础需求，所有应用均派生于此：

| 需求类型                 | 栈的单调性                | 遍历方向         | 触发弹出的条件（以当前元素 `x` 为例） | 弹出时栈顶元素获得的信息          |
| :----------------------- | :------------------------ | :--------------- | :------------------------------------ | :-------------------------------- |
| **下一个更大元素 (NGE)** | 递减（栈底→栈顶，值递减） | 左→右            | `x > 栈顶值`                          | 当前元素 `x` 是其右侧第一个更大值 |
| **下一个更小元素 (NSE)** | 递增（栈底→栈顶，值递增） | 左→右            | `x < 栈顶值`                          | 当前元素 `x` 是其右侧第一个更小值 |
| **上一个更大元素 (PGE)** | 递减                      | 左→右（或右→左） | `x > 栈顶值`（或倒序遍历）            | 弹出后栈顶即为左侧第一个更大值    |
| **上一个更小元素 (PSE)** | 递增                      | 左→右（或右→左） | `x < 栈顶值`（或倒序遍历）            | 弹出后栈顶即为左侧第一个更小值    |

**应用场景映射**：

- **直方图最大矩形**（LeetCode 84）：需同时获取每个柱子的 **NSE**（右边界）和 **PSE**（左边界），以计算宽度。
- **接雨水**（LeetCode 42）：用递减栈（NGE 思路）寻找凹槽边界。
- **子数组极值贡献求和**（如子数组最小值的和）：需计算每个元素作为最小值的左右边界（即 PSE 和 NSE），利用组合数学计算出现次数。
- **股票价格跨度**（LeetCode 901）：本质是求 PGE（上一个更大价格的距离），使用单调递减栈（相等时特殊处理）。
- **去除重复字母使字典序最小**（LeetCode 316）：贪心策略中需要判断后续是否还有当前字符，本质借助单调栈维护递增序列。

### 三、通用代码模板（抽象公式）

单调栈的实现可分为 **“单次遍历求解”**（适用于 NGE/NSE）和 **“双边界数组法”**（适用于需要左右边界的场景）。以下为两种抽象模板，不包含具体业务逻辑。

#### 模板 A：单次遍历求“下一个”关系（NGE / NSE）

**逻辑**：从左到右遍历，用当前元素清理栈中所有被它“压制”的元素，被弹出的元素即刻得到答案。

```python
def monotonic_stack_template(nums):
    n = len(nums)
    answer = [默认值] * n   # 默认值通常为 n（索引越界）或 0
    stack = []              # 存储索引

    for i in range(n):
        # 弹出条件：
        # - 求 NGE（下一个更大）：while stack and nums[i] > nums[stack[-1]]:
        # - 求 NSE（下一个更小）：while stack and nums[i] < nums[stack[-1]]:
        while stack and 比较条件(nums[i], nums[stack[-1]]):
            top_index = stack.pop()
            answer[top_index] = i - top_index  # 或 记录 nums[i]
        stack.append(i)
    return answer
```

**客观特性**：每个索引入栈一次、出栈一次，时间复杂度 **O(n)**。`answer[top_index]` 存的是距离（差值）或直接存储目标值。

#### 模板 B：双边界法（求左右两侧边界，用于组合计算）

**逻辑**：分别从左到右和从右到左各执行一次单调栈，得到每个元素的左边界（PSE/PGE）和右边界（NSE/NGE）。此模板不弹出时赋值，而是弹出后记录栈顶，或利用栈顶元素索引。

```python
def left_right_boundary_template(nums):
    n = len(nums)
    left = [-1] * n   # 左侧第一个更小/更大元素的索引，默认 -1 表示无
    right = [n] * n   # 右侧第一个更小/更大元素的索引，默认 n 表示无
    stack = []

    # 1. 求左边界（从左到右）
    for i in range(n):
        # 求 PSE（上一个更小）：弹出 >= 当前值的元素，保证严格更小（或根据相等情况调整）
        # 求 PGE（上一个更大）：弹出 <= 当前值的元素
        while stack and 比较条件(nums[i], nums[stack[-1]]):
            stack.pop()
        left[i] = stack[-1] if stack else -1
        stack.append(i)

    # 清空栈
    stack.clear()

    # 2. 求右边界（从右到左）
    for i in range(n - 1, -1, -1):
        # 求 NSE（下一个更小）：弹出 >= 当前值的元素（或根据相等情况调整）
        # 求 NGE（下一个更大）：弹出 <= 当前值的元素
        while stack and 比较条件(nums[i], nums[stack[-1]]):
            stack.pop()
        right[i] = stack[-1] if stack else n
        stack.append(i)

    return left, right
```

**客观特性**：两次遍历各 O(n)，总时间 O(n)，空间 O(n)。此模板在计算“以每个元素为最小/最大值的子数组数量”时必备。

### 四、关键边界与相等情况处理（客观准则）

- **严格大于 / 小于**（求严格更大/更小）：弹出条件使用 `>` 或 `<`，不弹相等值。这样当存在相等元素时，左边界或右边界会越过相等元素，使得范围计算结果符合“严格”定义。
- **非严格大于 / 小于**（允许相等作为边界）：弹出条件使用 `>=` 或 `<=`。用于需要处理重复值且要求边界不相等的场景（如去重问题）。

**选择依据**：取决于业务是否允许相等元素作为合法“更高”或“更小”。若题目要求“更高”（严格大于），则相等不弹出；若题目要求“不高于”或用于抵消重复计算（如去重），则等号需弹出。
