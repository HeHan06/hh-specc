# 内容阅读模板规范（ai-guide）

> 性质：本文件是 ai-guide 平台「内容正文结构」的唯一真相源。
> spec.md（Req-14）、plan.md（渲染与导入方案）、内容改造与 seed 导入均引用本文件，禁止在别处复制模板内容。
> 正文格式：Markdown（CommonMark + GFM），由 web-reader 的 react-markdown + remark-gfm 渲染。

## 1. 通用规范

1. 正文统一为 Markdown；结构骨架用二级标题 `##` 分节，小节用三级标题 `###`，条目用列表，代码用围栏代码块。
2. 每种内容类型（type）有固定「必需分节」，正文必须包含这些分节；可在末尾追加扩展分节。
3. `summary`：一句话概括（≤ 80 字），不复述正文。
4. `tags`：2~6 个，用于搜索与归类。
5. 拆分粒度：内容 = 最小内容单元。一道面试题 = 一条 `question`；一篇面经 = 一条 `interview`；一篇知识文 = 一条 `article`；一份简历 = 一条 `resume`。

## 2. 各类型分节骨架

### 2.1 question（面试题 / 题目）

必需分节（顺序固定）：

| 分节 | 标题 | 内容要求 |
|---|---|---|
| 问题 | `## 问题` | 题目原文，一句话 |
| 考察点 | `## 考察点` | 1~3 条，说明面试官想考什么 |
| 标准答案 | `## 标准答案` | 结构化回答；用 `###` 分小点，必要时用围栏代码块 |
| 关联 | `## 关联` | 相关概念 / 延伸题（可空则写「暂无」） |

### 2.2 interview（面试复盘）

必需分节：

| 分节 | 标题 | 内容要求 |
|---|---|---|
| 面试概览 | `## 面试概览` | 公司、岗位、轮次、时间、流程（各一行列表） |
| 面试问题与回答 | `## 面试问题与回答` | 每个问题一个 `### Qn：<问题>`，其下为回答要点列表 |
| 复盘总结 | `## 复盘总结` | 三个 `###`：做得好 / 待改进 / 下一步 |

### 2.3 article（知识文章）

必需分节：

| 分节 | 标题 | 内容要求 |
|---|---|---|
| 概述 | `## 概述` | 一段话，说明本文讲什么 |
| 正文 | `## 正文` | 多个 `### 小节标题`，每节为段落/列表/代码 |
| 总结 | `## 总结` | 要点回顾 |

### 2.4 resume（简历优化）

必需分节：

| 分节 | 标题 | 内容要求 |
|---|---|---|
| 简历正文 | `## 简历正文` | 简历内容 |
| 优化说明 | `## 优化说明` | `### 优化点` / `### 待优化` |
