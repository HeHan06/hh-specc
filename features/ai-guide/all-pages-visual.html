Agent 核心概念

AI 更新于 2026-09-01 · 共 5 个问题
01

AI Agent 是什么？和普通 Chatbot 有什么区别？

考察点
  • 是否理解 Chatbot 是单轮问答、Agent 是系统工程
  • 能否讲清 Agent 的能力增量
标准答案

Chatbot 是单轮问答，价值上限是「告诉你怎么做」；Agent 是围绕大模型构建的系统工程，核心是「规划 → 决策 → 执行 → 观察 → 再决策」的循环。

02

Agent 与 Workflow 的边界在哪里？

标准答案

Workflow 是固定流程编排；Agent 的路径由模型动态决定。能用确定性 Workflow 解决的，不过度使用 Agent。

03

一个生产级 Agent 由哪些模块组成？

标准答案

上下文构建、记忆管理、工具调用、任务编排、评测、安全审查、异常重试、可观测性。
