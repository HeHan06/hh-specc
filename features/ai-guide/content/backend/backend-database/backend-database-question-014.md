## 问题

联合索引 idx(a, b, c)，查询 `WHERE a = 1 AND b >= 2 AND c = 3`，哪些列可用索引？为什么？执行计划 key_len 会包含几列？

## 考察点

- 最左前缀原则与范围查询对后续列的阻断
- 索引条件下推（ICP）的作用
- key_len 的判断

## 标准答案

a、b 用于索引定位，c 仅用于 ICP（索引条件下推，即回表前在索引层直接过滤不满足 c=3 的记录，减少回表）过滤。key_len 只含 a、b。

原因：`b >= 2` 是范围，扫描区间内 c 列整体无序，无法参与边界收缩，故阻断后续列匹配。
