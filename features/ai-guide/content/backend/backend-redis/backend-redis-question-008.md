## 问题

为什么用 Redis 而不用本地缓存呢？

## 考察点

- 本地缓存与 Redis 在多维度的差异
- 分布式场景下 Redis 的优势

## 标准答案

| 特性 | 本地缓存 | Redis |
|---|---|---|
| 数据一致性 | 多服务器部署时存在数据不一致问题 | 数据一致 |
| 内存限制 | 受限于单台服务器内存 | 独立部署，内存空间更大 |
| 数据丢失风险 | 服务器宕机数据丢失 | 可持久化，数据不易丢失 |
| 管理维护 | 分散，管理不便 | 集中管理，提供丰富的管理工具 |
