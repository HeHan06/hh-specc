## 问题

一句话介绍 Java 语言，并简单说说执行流程。

## 考察点

- 对 Java 语言定位（面向对象、跨平台）的基本认知
- 对 Java 源码到运行的整体执行流程（编译、解释、运行）的掌握

## 标准答案

Java 是一种面向对象、跨平台的编程语言。执行流程包括编译、解释、运行三个阶段：

### 编译

.java 文件通过 javac 编译成 .class 字节码文件。

### 解释

判断是否是热点代码：热点代码走 JIT 即时编译器处理，非热点代码走常规的解释器逐行解释执行。

### 运行

最终打包成 .jar 文件执行。

## 关联

- JIT 热点代码识别
- JVM 运行时数据区域
